Teacher’s class guide
Class purpose: establish a confident starting point in whole-number reasoning and make pupils explain
how place value, estimation, and operation order support accurate calculations.

Learning outcomes
   Read, write, compare, and decompose whole numbers up to at least six digits.
   Identify the value and place of a digit; round numbers to a stated place.
   Estimate sums, differences, products, and quotients to judge whether answers are sensible.
   Calculate multi-step expressions using brackets and the agreed order of operations.
   Show steps, explain a strategy, and check a result using an inverse operation or estimate.
Materials: place-value chart/cards, number cards, mini-whiteboards or paper, pencils, board, timer, and
printed question sets. If resources are limited, use hand-drawn place-value columns and scrap-paper
number cards.

Teacher responsibilities
   Before class: prepare the number cards and question sheets; check the board examples and answer
    key.
   During class: model thinking aloud, invite more than one method, check understanding with mini-
    responses, and record misconceptions without labelling pupils.
   After class: mark Set A, group pupils flexibly, give a short targeted practice from Set B or Set C, and
    share one specific progress note with parents.

Parent/caregiver responsibilities
   Help the pupil arrive punctually with pencil, ruler, notebook, and water; support sleep and breakfast
    before the early lesson.
   Later at home, provide 10–15 calm minutes for the assigned practice. Ask “How did you decide?” and
    “How can you check?” rather than giving the answer.
   Sign or initial the practice log and tell the teacher if a question or concept caused difficulty. Keep the
    first class supportive, not a high-stakes test.

Differentiation and follow-up
   Entry: all pupils attempt Set A independently; teacher uses it as a baseline, not a selection test.
   Intermediate: pupils who are mostly secure attempt Set B with explanations and a peer check.
   Self-development: pupils ready for challenge attempt Set C, justify choices, and compare solution
    strategies.
   Support: use place-value columns, number lines, worked examples, and smaller numbers; revisit one
    misconception at a time.
