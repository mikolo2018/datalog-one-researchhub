How to use this question bank
This workbook provides five sets of equation questions for learners moving from Primary 6 into JSS
1. Difficulty increases gradually, from identifying an unknown and solving one-step equations to
handling brackets, fractions, variables on both sides, and short real-life problems.
   Each set contains 20 multiple-choice questions and 5 essay questions.
   For each multiple-choice question, choose one answer from A to D.
   Show clear working for every essay question and check solutions by substitution where possible.
   Teachers may use the sets for practice, revision, class tests, or mathematics enrichment.

Set progression
   Set 1 | Easy — Primary 6 foundation
   Set 2 | Easy to Intermediate — Primary 6 to JSS 1 bridge
   Set 3 | Intermediate — JSS 1 core equations
   Set 4 | Intermediate — JSS 1 applications and fractions
   Set 5 | Difficult — JSS 1 extension and multi-step reasoning
