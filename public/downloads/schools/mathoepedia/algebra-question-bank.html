How to use this question bank
This workbook introduces and develops algebra skills for learners moving from Primary 6 into JSS 1.
The sets progress from recognising variables, coefficients, constants, and terms to simplifying
expressions, substituting values, expanding brackets, identifying patterns, and modelling everyday
situations.
   Each set contains 20 multiple-choice questions and 5 essay questions.
   Choose one answer from A to D for each multiple-choice question.
   Show clear steps in essay answers and include units in real-life problems.
   Teachers may use the sets for class practice, revision, assessment, or mathematics enrichment.

Set progression
   Set 1 | Easy — Primary 6 foundation
   Set 2 | Easy to Intermediate — Primary 6 to JSS 1 bridge
   Set 3 | Intermediate — JSS 1 core algebra
   Set 4 | Intermediate — JSS 1 applications and multiple variables
   Set 5 | Difficult — JSS 1 extension and multi-step reasoning
